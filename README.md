# Acute Neurology Reasoning

A lightweight case-based tool for practicing how neurologists reason through acute consultations.

Core framework:

**Pace → Localization → Syndrome → Context-informed differential**

Each case presents a complete neurologic examination, followed by targeted maneuvers when they help answer a specific localization or severity question. Diagnostic tests may ask **“Why are you ordering this test?”** so the learner identifies what uncertainty the test is meant to resolve before seeing the result.

Cases include stroke, seizure, myelopathy, delirium, vestibular syndromes, and neuromuscular disease. Some have a clear answer; others preserve uncertainty.

Inspired in part by Ethan Meltzer’s *How to Think Like a Neurologist*. This is an independent educational project.

Cases are de-identified and adapted for education. This tool does not replace clinical judgment, supervision, current guidelines, or local protocols.

## Run locally

Open `index.html` in a browser. The project uses plain HTML, CSS, and JavaScript.
