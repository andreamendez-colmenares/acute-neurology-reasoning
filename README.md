# Stroke Code Simulator

Stroke Code Simulator is a lightweight, browser-based educational tool for neurology trainees. It uses evolving stroke-code presentations to practice deliberate neurologic reasoning under uncertainty.

The case flow emphasizes a consistent neurologic framework:

- **Pace** — how the problem developed over time
- **Localization** — where the findings point anatomically
- **Syndrome** — the coherent clinical pattern produced by pace and localization
- **Context + syndrome** — the basis for a prioritized differential diagnosis
- **Update** — revise the differential when new history, examination findings, imaging, or trajectory meaningfully change the picture

The activation reason is treated as context rather than a diagnosis. Learners are given the clinical history and raw examination findings, form their own working model, request additional information, re-examine the patient, and update their differential as the case evolves. Common explanations remain common; cases are not designed as hidden-diagnosis puzzles.

The project uses plain HTML, CSS, and JavaScript and can be hosted directly with GitHub Pages.

## Files

- `index.html` — page structure
- `styles.css` — responsive/mobile-first interface
- `app.js` — interaction and state logic
- `cases.js` — case content and reasoning metadata

## Educational use

This project is for education only. It does not replace attending supervision, institutional stroke protocols, or current clinical guidelines.
